### Python Challenge #N

```python
marks = 35

if marks >= 50 or marks == 35:
    print("Pass")
else:
    print("Fail")
```

**Answers**

- a) Fail
- b) Pass
- c) 35
- d) Error

<details>
<summary>Show Answer</summary>

**Correct answer: C**

Short explanation of why:

With or, the condition is true if either side is true. 

marks >= 50 is false, but marks == 35 is true, 

so the if block runs and prints "Pass".
